# QR Code Generator

A lightweight, modern, and responsive web application built with pure HTML5, CSS3, and Vanilla JavaScript that converts user-provided text and URLs into downloadable QR codes.

## Features

- **Dynamic QR Code Generation**: Instantly converts text and URLs into scannable QR codes.
- **Input Validation**: Validates user input before generation, providing real-time visual feedback and shake animations for empty fields.
- **Client-Side File Download**: Allows users to download generated QR codes directly as high-resolution PNG images.
- **Reset Functionality**: Quickly clears inputs and restores the interface to its default state.
- **Keyboard Support**: Press the `Enter` key inside the input box to generate codes instantly.
- **Responsive Design**: Built using CSS Flexbox for seamless usability across mobile phones, tablets, and desktops.

## Tech Stack

- **HTML5**: Semantic elements and accessible layout.
- **CSS3**: Flexbox, custom button styling, animations, and responsive media queries.
- **JavaScript (ES6+)**: DOM manipulation, event handling, and client-side download logic.
- **QRCode.js**: Lightweight client-side library for QR code matrix rendering.

## Getting Started

1. Clone or download this repository:
   ```bash
   git clone https://github.com/kavyasharma15/qr-code-generator.git
   ```
2. Open `index.html` in any web browser.
3. Enter any text or URL, click **Generate QR Code**, and download your QR code image.
